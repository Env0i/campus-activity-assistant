## 1. 定义

- **本工具**：校园活动预报名工具，含本机版（Windows 图形界面程序）与服务器版（自部署脚本与机器人）。
- **开发者**：编写并公开本工具源码的个人，仅通过 GitHub 与电子邮件与使用者沟通。
- **使用者（你）**：下载、运行或部署本工具的人。
- **学校系统**：你所在学校运营的学生端活动报名平台（含其 App 与网页）。本工具与该系统
  的运营方不存在任何隶属、合作或授权关系。
- **飞书**：服务器版用来推送消息的第三方即时通讯服务。
- **学校动作**：登录、登录态校验、活动列表拉取、报名提交与报名计划这些会访问学校系统的操作；
  校时、更新检查、帮助、设置与离线演示不属于学校动作。
- **直发报名**：报名开放时，程序直接调用学校的报名接口提交，不经过学校页面点击；
  **点击报名**：程序打开学校活动详情页并点击「立即报名」，只在直发不可用时兜底。
- **运行时密钥**：报名前向学校接口临时获取、只保存在本次运行内存里的密钥，用于计算
  报名请求的签名；不写入磁盘、不写日志。

## 2. 条款的接受与生效

- 本条款在程序首次需要执行学校动作之前完整展示，你点击「我已阅读并同意」后才开始执行学校动作；
- 你选择「暂不使用」时程序**不会退出**：帮助、设置、条款全文与离线演示照常可用，
  登录、活动列表和报名计划保持停用，并通过横幅与帮助保留重新同意的入口；
- 同一版本在你选择「暂不使用」后不再反复弹窗，但停用状态不变，直到你主动同意；
- **条款版本变化后，程序会再次展示条款并要求你重新点击同意**；此前任何一次的同意都不会
  自动延伸到新版本；
- 本条款可随时在程序「帮助 → 使用条款与隐私」内与随源码分发的本文件中查阅。

## 3. 软件性质

- 本工具是个人开发的辅助工具，**非官方作品**，与学校、学校系统运营方及飞书均无隶属、合作或授权关系；
- 免费开源，代码按 MIT 许可分发（见随包 LICENSE），不含收费项目、广告与商业推广；
- 按「现状」与「现有」提供，不承诺无缺陷、运行不中断或与任意环境兼容；
- 本工具只把「刷新活动列表、到点提交报名」这类重复操作自动化；报名默认走直发（直接调用
  学校报名接口，不经过学校页面），页面点击只在直发不可用时兜底；
  **它不构成报名代理，不承诺报名成功，名额与结果始终由学校系统决定**。
- 活动列表、活动详情与报名结果核对也直接调用学校接口；报名前会向学校获取运行时密钥，
  该密钥只放在本次运行的内存里，不落盘、不写日志；
- 开抢时会在短时间内多次提交报名请求；登录失效且具备自动登录条件时，会自动登录一次后继续，
  直到报名窗口关闭或本次重试预算用完。

## 5. 使用提醒

以下不是许可证条款，而是避免把工具用坏的提醒：

- 仅使用你本人的合法账号；
- 遵守学校规章制度与学校系统的用户协议，并自行确认你的使用方式不违反上述规定；
- 不要利用本工具干扰学校系统的正常运行，也不要以本工具对外承揽报名业务；
- 妥善保管你的电脑与账号，设备被他人使用产生的后果由你承担；
- 未满 18 周岁的使用者建议在监护人知情并同意后使用本工具。
- 用本工具登录会让同一账号在其他地方的登录失效（包括手机上的学校页面与服务器版）；
  被顶掉时程序会尝试重新登录，但不保证成功；
- 程序用浏览器填表登录时（包括服务器版的无人值守自动登录），会替你勾选学校登录页的《隐私协议》；直接调用登录接口时，完全不经过学校登录页；
- 学校规则方面：我们只找到学校登录页的《隐私协议》，其中没有关于脚本或自动化的条款，
  也没有找到其他校规；**本工具不声称合规**，以你账号名义提交的一切由你本人负责；
  这不代表学校允许自动化，可能存在我们没找到的规定；
- 只服务本人账号：本工具不提供多账号、批量占位或代他人报名。
