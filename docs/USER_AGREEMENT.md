## 1. 定义

- **本工具**：校园活动预报名工具，含本机版（Windows 图形界面程序）与服务器版（自部署脚本与机器人）。
- **开发者**：编写并公开本工具源码的个人，仅通过 GitHub 与电子邮件与使用者沟通。
- **使用者（你）**：下载、运行或部署本工具的人。
- **学校系统**：你所在学校运营的学生端活动报名平台（含其 App 与网页）。本工具与该系统
  的运营方不存在任何隶属、合作或授权关系。
- **飞书**：服务器版用来推送消息的第三方即时通讯服务。
- **学校动作**：登录、登录态校验、活动列表拉取、报名提交与报名计划这些会访问学校系统的操作；
  校时、更新检查、帮助、设置与离线演示不属于学校动作。

## 2. 条款的接受与生效

- 本条款在程序首次需要执行学校动作之前完整展示，你点击「我已阅读并同意」后才开始执行学校动作；
- 你选择「暂不使用」时程序**不会退出**：帮助、设置、条款全文与离线演示照常可用，
  登录、活动列表和报名计划保持停用，并通过横幅与帮助保留重新同意的入口；
- 同一版本在你选择「暂不使用」后不再反复弹窗，但停用状态不变，直到你主动同意；
- **条款版本变化后，程序会再次展示条款并要求你重新点击同意**；此前任何一次的同意都不会
  自动延伸到新版本；
- 本条款可随时在程序「帮助 → 使用条款与隐私」内与随源码分发的本文件中查阅。
