# 手机受限访问（PHONE_ACCESS）

手机控制是**可选高级功能**（组件键 `phone_control`，装 Segno 二维码）。
用户从电脑「帮助 → 跨设备访问」安装并启用后，在电脑旁的这台工具上
**显式开启**，才可以用手机浏览器查看本机活动缓存、做 8 项操作、必要时重登。
默认**完全关闭**，不监听任何端口。

- 基础安装只装运行必需项，**不带**手机控制，也不带「无人值守重登」
  （组件键 `relogin_ocr`，装 ddddocr 自动识别验证码）。
- 两个高级功能**互相独立**：可以只装手机控制、用人工验证码重登；
  也可以两个都装。未装 ddddocr 时重登永远保留人工输入路径。

> 边界先说清楚：这是个人受限适配层，不是远程服务器。远程只支持
> **Tailscale** 或 **Cloudflare 临时地址**，不把普通局域网做成产品入口。
> 既有 Tailscale 重启恢复、重新配对与提示场景已有用户验收；本次发布组件的
> 在线安装、Cloudflare 往返和新增故障边界仍需按 `design/evidence/` 清单验收。

## 一、怎么开启

1. 在电脑上的工具窗口打开「帮助」，安装「手机控制」高级功能。
2. 在「跨设备访问」选择 Tailscale 或 Cloudflare，点「开启手机访问」。面板会显示**地址、二维码**和一个 **6 位一次性配对码**。
   - 配对码只在这里显示，**不进 URL、不落日志**，5 分钟内有效、一码一次。
3. 手机上**先扫二维码，再输入配对码**：扫码只负责打开地址，配对靠电脑上这 6 位码，点「配对」。
4. 用完在电脑上点「关闭手机访问」，或直接关掉工具。

配过一次之后的行为，要看走哪条通道：

- **Tailscale（默认）**：地址固定，重启程序、重启电脑都**不用重新扫码**。
  本机只存一份**只含哈希**的设备信任，手机凭它自动恢复连接。
- **Cloudflare 临时地址**：每次重新开启都会换域名，**重启后需重新扫码**。

通道选择会被记住：下次打开帮助仍停在上次用的通道，点「重新检测」可以当场重探一次。
选 Tailscale 时程序下次启动会尝试自动恢复手机访问；选 Cloudflare 不会
（临时地址恢复了也打不开）。

只有两类远程通道：

| 允许 | 例子 | 说明 |
|---|---|---|
| Tailscale | MagicDNS 优先，100.x 地址备用 | 电脑和手机都登录同一 tailnet；本工具**不帮你装、不帮你启** |
| Cloudflare | `trycloudflare.com` 临时地址 | `cloudflared` 随「手机控制」组件包一起装好（内置 `bin/cloudflared.exe`）；关闭手机访问时隧道一并结束 |

Tailscale 是**默认**通道：地址固定（MagicDNS 名优先，100.x 备用），重启程序或
重启电脑后手机仍能直接打开，不用重新扫码；代价是电脑和手机都要自己装并登录
Tailscale。Cloudflare 走 Quick Tunnel，不用装账号也不用登录，`cloudflared`
由「手机控制」组件包自带——不用自己下载、不用配 PATH；但地址每次重新
开启都会变，只适合临时用一次，**重启后需重新扫码**。

### 什么时候「掏出手机就能看」

手机页只是控制器：真正读活动、报名、续登录的还是**这台电脑上的程序**。
所以能不能在外面打开，取决于两件事——通道，和程序有没有在跑：

| 情形 | 手机能不能打开 | 要不要重新配对 |
|---|---|---|
| 程序开着 + Tailscale | 能，地址固定 | 不用（设备信任一年有效） |
| 程序开着 + Cloudflare | 能，地址是本次隧道给的 | 同上，隧道还活着就免配对 |
| 程序关掉 | 打不开（没有任何东西在监听） | — |
| 重开程序 + Tailscale | 能，按上次的通道自动恢复 | 不用 |
| 重开程序 + Cloudflare | 要重新点「开启手机访问」，域名会变 | **要重新配对** |

想在教室里随时掏手机看，就把 Tailscale 设成默认并让程序常驻（关窗口时选
「最小化到任务栏」，别选直接退出）；Cloudflare 只适合临时用一次。

### 关窗口：隐藏、最小化、退出、先不关

关窗口会弹四选：**隐藏到后台**（从托盘或手机叫回来）、**最小化到任务栏**、
**退出程序**、**先不关**。对话框打开时焦点默认落在「最小化」——三个出口里
最轻、随时能回来的那一个。

「隐藏到后台」有一条硬门禁：**必须先有一条叫得回来的路**。托盘图标建起来，
或者手机上还连着一条未过期的会话，二者有其一才允许隐藏；两样都没有时工具
**拒绝隐藏并保持窗口可见**（提示「现在隐藏就没法把窗口叫回来」），不会把界面
藏成点不回来的样子。判断只回答「有没有」，不会把会话 token 或 cookie 交给界面。

手机页能做的事，就是电脑能做的事的精简版：看今天要参加的活动、开始/停止
报名计划、以及在登录失效时**在手机上重登**（电脑不在手边时这条最有用）。
本机回环只保留给内部调试，不作为帮助里的远程产品入口。普通局域网、公网 IP 和 IPv6 均不接受。
端口固定 **8765**。

### 走 Tailscale 时

- 先在电脑与手机上都装好 Tailscale 并登录同一账号（这一步在本工具之外完成）。
- 开启后优先扫二维码；手机浏览器打开地址后，再输入电脑上显示的配对码。
- 传输安全**依赖 Tailscale 的加密**：这是 HTTP 明文服务，cookie 不谎加
  `Secure`（那会让 HTTP 直接不可用），离开 tailnet 就不要用。

## 二、8 项操作

配对成功后手机上能做：

1. **读取完整缓存**：活动、登录结论、计划快照、北京时间、条款状态（都是本机缓存）。
2. **筛选**：名称/关键词、报名状态（全部/可报名/已报名）、开放时间（不限/今天/7 天内）。
3. **勾选可报名活动**：时间未知或已截止的场次不可执行；资格与冲突仍由电脑端缓存最终裁决。
4. **三种重试模式和次数**：2 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 自动延长（最多 25 分钟）/ 直到报名截止；次数 0 = 不限。
5. **开始 / 停止 / 取消单场**：停止与取消都要**二次确认**；未确认的开始只用同一个请求 ID 只读对账，不鼓励重复点击。
6. **权威进度**：倒计时优先用后端已接纳的截止（含合法扩窗后的权威值）。
7. **日志**：最近的运行记录（截断、脱敏）。
8. **验证码重登**：见下节。

手机页面会**单飞轮询**（前台空闲 15 秒、有报名计划或重登进行中 2 秒，断线
指数退避最多 15 秒；进后台取消定时器）。状态超过 30 秒没更新就显示「离线/未知」并禁用
「开始」和「重登提交」，「停止」仍然可点。切回前台按**事件游标补齐**
后台期间漏掉的状态与事件；断线太久就整体重置快照，**不会自动重发写操作**。

## 三、手机重登（人工验证码）

登录失效时可以**在手机上重登**，但要先在电脑上做一步准备：

1. **电脑上**：在帮助里的「账号与登录」填写账号密码，可只作本次内存准备，也可选择保存；保存不要求安装 ddddocr。
   - 保存版本使用 Windows 当前用户 DPAPI；手机页面永远拿不到账号、密码或密文。
   - 不保存时仍可人工输入验证码，关闭工具后本次内存准备会清除。
2. **手机上**：点重登。已启用 ddddocr 时由电脑自动识别；无法识别或连续三次验证码错误后交给手机人工填写（只接受 `data:image/png;base64`）。
3. 抄下 4 位字母数字验证码，点「提交验证码」。
   - 每个验证码**只能用一次**；学校接口没有验证码倒计时，也没有提交次数上限。
     输入错误时按接口返回刷新验证码，工具不会自动乱猜验证码。
4. 成功后工具会自动刷新登录结论与活动列表；**不会自动重新开始计划**——
   你要重新选场次、再点开始。

三种情况会明确拦下：

- **还没准备**：手机上提示「请先在电脑上准备账号密码」。
- **报名计划还在跑**：提示先**停止计划并等终态**，再重登。工具**绝不会**
  自动重发结果未知的任务、也不会自动重建计划。
- **演示模式**：不联网，不启动重登。

**桌面原本的手动登录照旧可用**（在真实浏览器里自己输账号密码和图形
验证码），那条路径的「密码不落盘」承诺不变。

## 四、安全边界（值得知道的实现取舍）

- **配对**：6 位密码学随机码，5 分钟有效、一码一次；单 IP 连错 3 次锁 60 秒，
  换 IP 也逃不过全局限速。
- **会话**：256 位随机 cookie，`HttpOnly` + `SameSite=Strict` + `Path=/`，
  8 小时、只存内存、停服务即撤销；校验不刷新寿命。
- **设备信任**：只有 Tailscale 通道会额外发一枚 `campus_phone_device`
  （`HttpOnly` + `SameSite=Strict`，一年），用来在程序重启后免配对恢复；
  磁盘上只存它的 **SHA-256**，不存原文。手动「关闭手机访问」会撤销全部
  设备信任，直接退出程序则保留。Cloudflare 通道**永远不会**走这条恢复路径。
  可读 CSRF 标记保留一年用于首屏发现旧设备；真正授权仍要求有效会话或已登记设备，标记本身不能登录。
- **写请求**：必须带配对时发的 CSRF 头，`Origin` 必须逐字等于服务自己的
  地址，拒绝跨源 / 无 Origin / 伪造 Host。
- **动作白名单**：手机只能调 8 项操作对应的入口；`shutdown`、`open_data`、
  `update`、改条款、改路径这些**永远不可达**，也不会反射任意内部方法。
- **静态页**：只认固定的 4 个文件（入口/样式/脚本），杜绝目录遍历。
- **请求体**：≤ 64 KiB，拒绝非法 JSON / 坏 UTF-8 / NaN；异常不回堆栈。
- **事件**：手机只拿到脱敏、截断后的事件；缓冲最多 400 条，断线太久就整体
  重置快照，不漏中间状态装作连续。

## 五、可选组件与通道选择

- 基础安装不带 Segno、ddddocr 或 cloudflared：手机控制是**可选组件**，不装也能正常用桌面工具。
- 「手机控制」组件包**必须自带** `cloudflared`：包内 `bin/cloudflared.exe`，版本写死为
  `2026.10.7` 并带 SHA-256。安装前逐项校验——没声明、哈希对不上、版本漂移一律拒绝；
  `relogin_ocr` 包里也不许夹带。
- 装组件有两条路，都指向同一份校验逻辑：
  - **一键安装**：帮助 → 跨设备访问 → 「下载并安装组件包」。程序从 GitHub Release
    取与当前版本配套的资产，下载完自动校验 SHA-256、版本与 cloudflared，再交给安装器。
    下载过程有进度条和「取消下载」，失败会写清是限速、断网、还是资产缺失。
  - **导入组件包**：自己拿到 ZIP 后选文件安装。校验失败会回滚成原来那份，不留半个装坏的组件。
  - 无论哪条路，装完都**不会自动升级**：装的是哪个版本就用哪个版本，换版本要重新装一次。
- **长期通道是 Tailscale**：地址固定（MagicDNS 名），重启程序、重启电脑后手机仍能用同一个
  地址打开，配对一次就一直免配对。**Cloudflare 是临时通道**：每次开启都是新的
  `trycloudflare.com` 地址，**退出或重开后旧地址立刻失效**，手机需要重新扫码配对。
  要「人在外面也能随时掏手机」，就用 Tailscale 并让程序常驻。
- 通道选择会被记住（`phone_access.preferred_channel`）。只有 Tailscale 会按
  `tailscale_autostart` 自动恢复；Cloudflare 永不自恢复——临时地址自恢复没有意义，
  而且会在用户不知情时对外开一个入口。
- 下载组件与检查更新走系统代理（Windows 的 `ProxyEnable/ProxyServer` 或环境变量）；
  **学校接口一律直连**，不受代理配置影响，也不会把登录态经代理转发出去。
- 账号密码保存用 Windows 当前用户 DPAPI，密文只落本机数据目录；手机端永远只拿到重登阶段、
  验证码图片和人工输入结果。
- ddddocr 缺失、识别失败或结果不是 4 位字母数字时保留人工验证码输入，不能把缺组件当成登录成功。

## 六、明确没做的

- **真实手机 / 真实 Tailscale / Cloudflare / 学校链路的现场验收由用户执行**，
  清单见 `design/evidence/2026-10-31/phone-access-channel-redesign-acceptance.md`。
- 不代他人报名、不批量提交、不做任何绕过风控的操作。
- 列表空态、服务器版、打包发布、C01 直发边界**不在本次范围**。
- 电脑必须**保持唤醒**：手机只是遥控器，真正执行报名的还是电脑上的工具。
