# 主窗口成对截图（实现 vs 原型）

日期：2026-11-08。比例 1，Edge 无头。`<画板>-app.png` 是实现（local/ui 经 QA 桥离线渲染，业务时钟定在 14:20:05，数据集为 appshot 的 11 行集），`<画板>-proto.png` 是原型同名画板。

两侧数据集不同（原型有「可报名 8」，实现数据集是 9；原型每行不带「报名截止」和状态胶囊），所以行密度、计数、行内标签的差别是数据与既有版式造成的，下面不逐条重复；只记本批改动相关的差异。

复现：原型 `pwshot.py <原型目录> <输出> 1 1 <画板>`；实现用 QA 桥脚本（`__QA_STATE`、`__QA_EMIT`、`__QA_SECOND_OPEN()`）。

## 逐画板

- Filters：展开「更多筛选」，开放=今天，按钮显示「更多筛选 (1)」。四个下拉（开放、排序、签到、签退）与原型同序同文案。差异：原型默认值下按钮无计数（另附 FiltersDefault 成对，实现默认值下也无计数）；计数的写法实现是「更多筛选 (1)」。
- FiltersDefault（补充）：默认值展开，与原型 Filters 同状态。四个下拉与摘要行一致，实现的下拉框偏高一点、行距略大。
- NoResult：搜「篮球」。标题「没有符合筛选的活动」、副句「一共 11 场。换个关键词，或清除筛选看完整列表。」、按钮「清除筛选」与原型同文案。差异：实现的副句与按钮上下贴得更紧，搜索框带清除叉；计数「0 / 11 场」一致。
- ListErr：标题「活动暂时没加载」、副句、「刷新」按钮、右栏「需重试」「活动暂时没加载」「还差一步：活动列表还没加载」与原型一致。评审修正后：副句里「刷⁠新」用 U+2060 连住，不再被拆开；运行记录是「活动列表没加载：连不上学校站点」，与原型一致。差异：顶部筛选条实现显示「可报名 0 / 已报名 0 / 全部 0」，原型没有数字；右栏底部橙色「刷新」两侧都有，无缺块。
- Broken：组件缺失。右栏「不可用 / 暂时不能报名 / 程序组件缺失，处理办法在顶部提示里」「! 程序组件缺失」「还差一步：程序组件缺失，看顶部提示」一致。差异：顶部横幅文案不同，原型「程序组件缺失。重新下载完整版本，下载页在设置的“版本与更新”里。」，实现「程序组件缺失。无法找到所需程序组件。请重新下载完整版本，再选择「重新检查」。」；空态副句原型「程序组件缺失，修好之前看不了活动。处理办法在顶部提示里。」，实现「组件有问题，处理办法看页面顶部的提示。」；胶囊原型「登录待确认」（橙），实现「已登录」（QA 桥这一场景的登录检查返回有效，非实现缺陷）。
- Expired：登录失效，勾了一场。横幅「登录已失效。重新登录后可以继续。」+「重新登录」、胶囊「登录已失效」、右栏「! 登录已失效」「还差一步：登录已失效」+「重新登录」与原型一致。差异：运行记录最后一行是「[X] 登录态已过期（4001）」，原型是「活动列表已更新，共 11 场」；原型里「心理健康工作坊」行下有「与已选的「人工智能与未来职业」时间重叠」一行，实现截图里该行没有这行内联提示。
- Slept：只到横幅阶段（计划还在，没出结果页）。横幅「电脑刚才睡眠了约 23 分钟。期间「人工智能与未来职业」「志愿服务培训」到了开放时间，没有提交。」，点名了两场，有「知道了」。差异：原型是「电脑刚才睡了约 23 分钟」，实现是「睡眠了约」；此时右栏是「准备报名」而不是结果页。
- SleptResult：横幅 + 结果页同屏，与原型 Slept 同状态（原型 Slept 画板本身就是这个同屏状态，所以 SleptResult-proto.png 是 Slept-proto.png 的副本）。右栏「错过了 / 2 / 错过了 / 电脑睡眠，错过了开放 / 两场各一行「错过了」+「电脑睡眠期间到了开放时间，没有提交。」/ 重新选择未成功的场次 / 完成，回到活动列表」文案与结构一致；时刻表两行有「错过了」胶囊。差异：横幅文案同 Slept（「睡眠了」）；原型副句「运行计划时别让电脑睡眠：在 Windows 电源设置里把睡眠改成“从不”，并保持插电。」实现一致；运行记录实现是「登录状态暂时无法确认：志愿服务培训 · 本场没有提交」，原型是「计划已结束」；时刻表里被错过的两行，实现在「距开放」列显示「错过了」胶囊。
- NarrowResult（430x820）：结果页「部分完成 / 1 已报名 1 名额已满 1 待核对」「报名计划部分完成」「有 1 场需要到活动页核对，结果以学校为准。」三行任务与「完成，回到活动列表」一致。评审修正后：窄档（401–560px）顶栏一行放下，只留图标、时间、登录胶囊（校验时间副字收起）、刷新/设置/帮助，与原型同构；≤400px 仍换行。差异：原型待核对一场有「打开活动页」「刷新核对」两个按钮，实现只有「刷新核对」；第一场副句是 QA 桥的假数据，不比较；运行记录原型「计划已结束」，实现「结果待核对：志愿服务培训 · …」被截断；「返回列表」实现带下划线。
- SecondRun：横幅「工具已经开着。刚才又打开了一次，已切回这个窗口。同一台电脑只运行一份，免得同一场被提交两遍。」+「知道了」与原型逐字一致；运行记录「又打开了一次，已切回这个窗口」一致。差异：胶囊实现是白底「已登录」无「14:20 校验」，原型绿底带校验时间（计划运行中的既有行为）；步骤「本次尝试截止」实现有 14:32:00，原型是「待定」。
- Medium（900x700）：原型这块画板是草稿态（scene=draft，已选 3 场）而不是修改中，所以成对图是草稿态：dock「已选 3 场 / 1 场立即报名，2 场预报名等开放 / 查看计划 / 开始」文案与位置一致。差异：实现的「地点」列里「大学生活动中心二楼」折成「…二 / 楼」，单字掉行；原型里同一画板另有书香校园行标题末字「赛」单独成行（见下断行检查）。
- MediumEditing（补充，只有实现图）：dock 为「修改中：已选 2 场 / 计划已暂停，改完要重新开始」+「查看计划」「开始」，符合任务要求的修改中文案；原型没有对应的 Medium 修改中画板，无法成对。
- NarrowWarn（430x820）：计划栏已打开，顶部「网络断开了。恢复以后点“刷新”。」+「重新检测」，红色提醒「现在连不上网。到开放时间还没恢复，就提交不出去。」，橙色「要等到后天 09:00，自动登录没开。中途登录失效要你重新登录；开放前 100 秒内失效，那场就结束。」+「去保存」，「有场次在 24 小时以后才开放，计划要一直运行到那时。这段时间电脑不能关机或睡眠。」，底部「仍然开始报名计划」，文案与原型同。差异：原型有四条提醒，多一条「「志愿服务培训」没报名截止时间……只会尝试 2 分钟」，实现数据里这场有截止时间所以没有；顶栏评审修正后一行放下；24 小时那句现为「这段时⁠间电⁠脑」，「重⁠新登录」也已连住，断行扫描 clean。
- Policy：右栏展开「尝试时长」「最多提交次数（0 = 不限）」「改用页面点击时显示浏览器」，选项文案「2 分钟」「收起」与原型一致，下拉未展开，「自动延长（最多 25 分钟）」选项在本图里看不到。差异：原型的控件靠右对齐，实现控件紧跟标签，复选框在文字前；原型「心理健康工作坊」行下的重叠提示实现没有。

## 脚本说明

- Slept 用页面内把单调时钟拨快 23 分 20 秒并同时重定业务时钟来模拟睡眠，两张图都由真实心跳检测触发横幅。
- 原型 Filters 画板展开且各项为默认值；实现 Filters 为带一个非默认值的状态，另附 FiltersDefault 作同状态对照。
