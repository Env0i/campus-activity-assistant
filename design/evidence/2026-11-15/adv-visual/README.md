# 高级功能「一项一行」原型定稿截图（2026-11-15）

把设计画布「工作台视觉方案」里三块效果稿搬进原型 `design/prototype/workbench-2026-11/`，供用户看 Edge 截图定稿，定稿后再按原型 1:1 写执行计划。三块是：设置方案一（一项一行，点开看详情）、组件状态怎么过渡、顶栏状态总表的手机一组。

- **改了什么（只动原型）**：设置抽屉「高级功能」组的手机访问、验证码识别两节改成一行一张卡——图标、名称、圆点加一句状态、一个主按钮、展开箭头；进度条长在这一行里；说明、通道、配对、地址、位置收进展开区。圆点颜色含义固定：灰没装或没开、蓝正在做、绿能用、琥珀要留意、红坏了。顶栏手机标识补「正在开启…」「正在停止…」转圈、「等手机连接」慢闪、「已断开 · 2 分钟前」灰色；手机详情卡补已断开。取消下载不再留「下载已取消」那句。登录组、程序组没动（后面另排）。
- **状态的说法照已落地的代码与画板决定**：检查中有上次结论时保留原字、只把圆点变蓝并收起按钮，没有结论时写「正在确认组件状态…」；检查超时写「另一个窗口正在安装或更新组件，已等 30 秒」并给「重试」；读不到保留原字，下面一句「暂时读不到组件状态」并给「重试」；坏了写「加载失败」、按钮「重新安装」、下面一句「组件文件不完整。重新安装不会动你的账号和设置。」（深红小字，不是红条）；重新安装失败回到坏了，另加下载失败的红条。
- **截图（本目录，1280×800，无头 Edge）**：新画板 AdvCheck（手机没结论、识别保留原字）、AdvTimeout（手机检查超时、识别读不到）、AdvBroken（手机需要更新、识别坏了）、AdvReFail（手机已停用、识别重新安装失败）、PhGone（已断开，抽屉）、PhGoneTop（已断开，顶栏与详情卡）、PhStarting / PhStartingTop（正在开启）、PhStopping（正在停止，顶栏）、AdvVerify（手机校验中、识别安装中）、AdvUpdFail（手机更新失败回到需要更新并给导入兜底、识别没有缓存时读不到）、PhStartFail（上次没开成，按钮「重新开启」）、PhDownload（手机组件下载中）、NarrowSettings（窄窗口，430 宽）；已有画板在新排版下的样子：Settings、PhoneSetup、PhoneWait、PhoneLinked、CompOk、CompFail、CompAfter、PhFail、PopPhone。
- **对照画板转移表**：组件那台的每个状态（没装、下载中、校验中、安装中、已启用、需要更新、坏了、已装没启用、上次失败、取消后回到没装、安装失败回原态、检查中两种、检查超时、读不到两种）与手机访问那台的每个状态（已停用、未开启、开启中、等手机连接、已连接、已断开、停止中、上次没开成）都至少有一张静态画板；「刚装好多一句」「点重试回到检查中」「手机又来了」用原型里的演示按钮可以点出来。
- **复跑**（仓库根）：

  ```bash
  python -m http.server 8790 --bind 127.0.0.1 --directory design/prototype/workbench-2026-11
  # 另开一个终端，每张图用一个新的空配置目录
  msedge --headless=new --disable-gpu --hide-scrollbars --user-data-dir=<新的空目录> --window-size=1280,800 --virtual-time-budget=6000 --screenshot=<输出.png> http://localhost:8790/AdvCheck.dc.html
  ```
