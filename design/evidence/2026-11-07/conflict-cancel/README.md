# 冲突可见与取消报名：原型画板截图（2026-11-07）

计划 20261107-conflict-cancel 的 proto-boards 任务产出（sonnet 起稿，Claude 返工定稿）。Edge 无头截图，1 倍，画板原尺寸。源码在 `design/prototype/workbench-2026-11/`。

复现：按该目录 README 起本地静态服务器，打开 `http://127.0.0.1:8790/<画板名>.dc.html`。

- `Conflict-proto.png`：已有的「时间重叠」画板，改后的列表行。与已报名活动重叠的「就业指导午间沙龙」勾选框置灰，状态格写虚线的「不可加入」，行内不再有「不能加入」那句。
- `ConflictTip-proto.png`：悬停「模拟面试」行，弹出原因气泡。已报名的「宿舍查寝」可取消，所以最后一句是「想报这一场，要先取消……」加「去已报名那场」。
- `ConflictNoCancel-proto.png`：同一个气泡，已报名那场报名后不能取消，最后一句是「……报名后不能取消，这一场报不了。」
- `CrossDay-proto.png`：跨天时段「活动 11月8日 22:40 – 11月10日 23:20（跨3天）」，未报名行的「报后可退」「报后不可退」，计划栏卡片里的「报后不可退」。没有气泡。
- `CancelAsk-proto.png`：点「取消报名」后，行下展开红色确认块，按钮是「不取消」和「确认取消报名」。
- `CancelBusy-proto.png`：「正在取消…」，按钮禁用；刷新和开始报名计划置灰，计划栏说明原因。
- `CancelDone-proto.png`：已取消。结果句是绿色；这一场不再是已报名，回到「正在开放」，与它重叠的「模拟面试」也不再被挡。
- `CancelRefused-proto.png`：学校没有取消，红色结果句带学校原话（演示用占位原话）。
- `CancelUnknown-proto.png`：没能确认是否已取消，琥珀色结果句；行仍是已报名。
- `PhoneConflict-proto.png`：手机页，点按「模拟面试」展开原因；已报名的「宿舍查寝」写「可取消至 11月8日 14:00，在电脑上或学校网站取消。」，没有取消按钮。

- `ConflictPast-proto.png`：气泡第三种句子，已报名那场的取消时间已过。
- `ConflictUnknown-proto.png`：气泡第四种句子，能不能取消还没查到。

只在场景里支持、没有单独画板的状态：`cancelprecheck`，取消前核对没过，结果句「现在不能取消：<原因>」。

Claude 返工时统一的口径：日期一律照列表原有写法「11月8日 22:40」；跨天写「11月8日 22:40 – 11月10日 23:20（跨3天）」，「（跨3天）」不拆行；「不可加入」的行不再显示距开放的倒计时；时间条日期居中，重叠段是浅红底加虚线边界。

## 实现截图（`-app.png`，与上面的 `-proto.png` 成对）

2026-11-07 抓取：无头 Edge，1 倍，画板原尺寸（桌面 1280x800，手机 390x844）。桌面页是 `local/ui` 原样加载，只注入 `local/tests/fixtures/runtime_bridge.js`；手机页是 `local/ui/m` 静态加载，状态接口用桩。数据按原型造：已报名的「宿舍查寝」跨三天（11月8日 22:40 – 11月10日 23:20），重叠的未报名「模拟面试」（11月9日 08:00–17:00）和「毕业生双选会志愿者招募」（11月10日），「职业规划讲座」报后不可退，「社区志愿服务日」报后可退，另有一场同一天的已报名「学术诚信专题报告」。业务时钟定在 11月5日 14:20:05。全部离线，没有页面错误和控制台错误。脚本没有入库，复现方式是按上面的数据对着桥接桩跑。

通用差异（每张桌面图都有，列表壳本身还没跟上原型，与冲突/取消改动无关）：顶部多一行筛选下拉；活动行里「无需签到、无需签退」是蓝底小标签，原型是纯文字；没有「2 分 / 工资 20」角标（造的数据里没给）；同日举办时间写「活动 明天 14:00 – 15:30」，原型写「活动 11月6日 14:00–15:30」，且短横两侧多空格；已报名两行的顺序与原型相反（宿舍查寝在前）。

- `ConflictTip-app.png`：悬停「模拟面试」，气泡向下展开，已报名那场可取消。标题、两行时段、时间条、图例、「想报这一场，要先取消「宿舍查寝」的报名，11月8日 14:00 前可以取消。」加「去已报名那场」与原型逐字一致，断行也一致（「前可 / 以取消。」）。气泡压住下面「毕业生双选会」的状态格和已报名行，与原型一样。差异：只有通用差异。
- `ConflictNoCancel-app.png`：同一个气泡，句子是「「宿舍查寝」报名后不能取消，这一场报不了。」，一行放下，没有链接，没有孤字，与原型一致。
- `ConflictPast-app.png`：句子「「宿舍查寝」的取消时间已过（截至 11月4日 18:00），这一场报不了。」，在逗号后断行，「这一场报不了。」整句在第二行；原型断在「（截至 11月4日 / 18:00），」。文案一致，断行位置不同，没有孤字。
- `ConflictUnknown-app.png`：句子「「宿舍查寝」能不能取消还没查到，刷新后再看。」，与原型一致。
- `CrossDay-app.png`：勾选「职业规划讲座」，行内「报后不可退」（琥珀色）、「社区志愿服务日」「报后可退」、宿舍查寝「活动 11月8日 22:40 – 11月10日 23:20（跨3天）」一行放下；已报名行状态格是「已报名」「可取消至 11月8日 14:00」「取消报名」；计划栏卡片带「报后不可退」。与原型一致。差异：社区志愿服务日行多了「报名截止 明天 12:00」；计划栏卡片里的举办时间写「活动 明天 14:00 – 15:30」。
- `CancelAsk-app.png`：点「取消报名」，行下展开红色确认块，文案「取消「宿舍查寝」的报名？取消后名额可能被别人报走，不能撤回。」，按钮「不取消」「确认取消报名」，与原型一致。列表自动滚动，把确认块放进可视区，第一行被表头截断，原型同样如此。
- `CancelBusy-app.png`：确认后按钮变灰写「正在取消…」，顶栏「刷新」置灰，「开始报名计划」置灰，计划栏说明「还差一步：正在取消报名，等它结束再开始」，与原型一致。差异：为了对上原型，勾选了「社区志愿服务日」，列表因取消流程滚动，这一行被表头压住上半截。
- `CancelDone-app.png`：绿色结果句「已取消「宿舍查寝」的报名，学校记录已核对。」在该行下方；该场回到「正在开放」（计数「可报名 5、已报名 1」、「正在开放 2 场」），「模拟面试」与「毕业生双选会」不再显示「不可加入」，改为倒计时「19 时 39 分」「1 天 18 时」，与原型一致。差异：宿舍查寝行带「报名截止 11月8日 14:00」，原型没有。
- `CancelRefused-app.png`：红色结果句「学校没有取消这场报名：活动已开始，不能取消」，行内仍是已报名加「取消报名」，与原型一致。
- `CancelUnknown-app.png`：琥珀色结果句「没能确认是否已取消，请到学校网站的活动详情里核对。」，行仍是已报名，与原型一致。
- `PhoneConflict-app.png`：点按「模拟面试」展开原因，面板文案与原型一致（含「（跨3天）」在窄屏下落到第二行、「去已报名那场」链接）。差异：手机页还没按原型改版——没有「可报名 / 已报名 / 全部」分段，分区是「今天要参加 / 即将开放 / 已报名」，没有「明天 / 后天」；行内先写原始开放和截止时间（「开放 2026-11-06 10:00:00 · 截止 …」），「不可加入」独占一行，举办时间在其下一行；没有地点和分数角标。
- `PhoneConflict-signed-app.png`（额外）：展开「已报名 2 场」，宿舍查寝写「11月8日 22:40 – 11月10日 23:20（跨3天）」和「可取消至 11月8日 14:00，在电脑上或学校网站取消。」，没有取消按钮，与原型一致，「学校网站取消。」没有孤字。
- `ConflictFlip-app.png`（额外）：悬停靠下的「毕业生双选会」，气泡翻到行上方（`data-placed=up`），箭头对准「不可加入」，没有被裁。
- `Narrow-conflict-app.png`：820x800，悬停「模拟面试」，气泡向下，贴右侧，箭头对准标签，文案完整无截断。地点列在这个宽度下隐藏。

核对结论：气泡上下翻转正确（下方放得下向下，放不下向上）；所有截图里没有被截断的字，也没有孤字（「这一场报不了。」「（跨3天）」「学校网站取消。」都是整句）。已报名行的状态格自上而下是标签（20px）、「可取消至」（14px）、「取消报名」按钮（24px），总高 66px，行高 79px，上下各留 6 到 7px；1280 和 820 宽度下都放得下，820 宽时「可取消至」比状态格宽 12px，向左伸出，没有压到其他列。
