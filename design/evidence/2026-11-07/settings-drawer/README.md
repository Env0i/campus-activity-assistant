# 设置抽屉：实现与原型成对截图（2026-11-07）

每个画板两张图：`<画板>-app.png` 是现在的桌面界面，`<画板>-proto.png` 是原型。Settings 的原型图取自 `2026-11-04/ui-gap/`，其余取自 `2026-11-06/prototype-backfill/`，没有缺图。

复现：用 QA 桥（`local/tests/fixtures/runtime_bridge.js`）在 1280x800（NarrowSettings 为 430x820）的 Edge 无头窗口里打开 `local/ui`，全程不联网。QA 桥没有 `phone_access_state`，每个画板用页内替身给出组件、通道、账号快照；账号只用打码占位 `st****01`，配对码和二维码是占位数据（二维码是示意图案，不是真码）。抽屉都是点真实的「设置」按钮打开，停止确认、清除确认、再配对一台手机也是点真实按钮。

## 各画板都有的差异（下面各行不再重复）

抽屉外框已和原型对齐，并在各画板截图里核对过：宽度 34rem（窄窗时占满），深色标题栏加琥珀竖条、白字、无框的浅色关闭钮，胶囊形分组按钮，浅灰条加小号灰字的分组标题，白色整宽区块，程序一组各行同样是白底、细线相隔。下面是仍然存在的差异。

- 「会装到 / 装在」位置框：实现显示 QA 桥给的 `…\advanced\<组件名>`，原型是示意的用户目录路径。
- 抽屉外的活动列表：原型有「分」「工资」标签，顶部没有筛选条；实现没有这两个标签，有筛选条。这不属于抽屉，仅记录。
- 「程序」一组：「关闭窗口时」的下拉框实现是灰底带描边，原型是白底粗体；「版本与更新」显示 QA 桥的 1.1.1，带「检查更新」和「前往下载页」两个按钮，原型是 1.2.0，只有「检查更新」，下方是「打开发布页」链接；「条款与隐私」一行的措辞和日期格式也不同（实现来自 QA 桥的条款数据）。

## 画板

- **Settings**：手机访问已装未开启，验证码识别没装，没有账号。一致：手机访问标题、「未开启」chip、两张通道卡（Tailscale 已连接选中、Cloudflare 可用）、「开启手机访问」按钮、验证码识别的「下载并安装」、登录恢复的「填写账号密码」和「未启用」结论句。差异：实现在手机访问下多一个「装在」位置框，原型这一态没有；验证码识别的体积句，原型是「约 31.6 MB」，实现是「大小以发布页为准（现在读不到）」；Tailscale 通道说明在实现里多折了一行；登录恢复下实现多「最近一次登录」「手机上重新登录」两行（代码注明原型没有、保留）。
- **CompAfter**：手机访问已装未开启，验证码识别已装未启用。一致：手机访问下的「装在 + 打开所在文件夹」框、验证码识别标题旁「未启用」chip、右侧「启用」按钮、「已装好（版本 1.2.0），还没启用……」一句和「这一项关系到自动登录……」一句，文案逐字相同。差异：「装在」框内路径行的写法不同；其余是通用差异。
- **CompNoSize**：两项组件都没装。一致：两处右侧「下载并安装」、说明句、「会装到」框、体积句都是「大小以发布页为准（现在读不到）」，逐字相同。差异：只有通用差异。
- **PhFail**：手机访问下载失败。一致：右侧按钮改「重新下载」，红条「下载没有完成：连不上发布页，可以重试。」，下面「一直下载不了的话……导入已下载的组件包」一句。差异：原型手机访问体积是「约 18.4 MB」，实现是「大小以发布页为准（现在读不到）」；验证码识别一节同样缺具体体积。
- **PhStopAsk**：手机已连接，关闭确认展开。一致：「手机已连接」chip、绿条、琥珀色「出门前建议保存账号密码」提示、地址与备用地址、「地址固定……」一句、红底确认块（文案、「先不关闭」「确认关闭」）、确认块出现时收起「关闭手机访问」。差异：只有通用差异。
- **PhAddPair**：手机已连接，点了「再配对一台手机」。一致：绿条、琥珀提示、配对区的说明句「手机扫码打开页面，再输入这 6 位配对码」、倒计时「4:59 后失效，一码只能用一次」、地址与备用、「关闭手机访问」。差异：配对码是普通粗体文字，原型是点阵屏；二维码在实现里放在右侧小块，原型是左侧大块、整块深色底并带「原型示意，不能扫」。
- **CredOcrOff**：已保存账号，验证码识别已装未启用，滚到「登录」。一致：「更换」按钮、「已保存账号 st****01。」、橙色结论句（识别已装、还没启用、去“高级功能”点“启用”）、「清除已保存」按钮。差异：滚动停下的位置不同，实现上方露出验证码识别的一句说明，原型露出「装在」框；实现多「最近一次登录：暂无记录。」「手机上重新登录……」两行；结论句断行位置不同。
- **CredClear**：已保存账号，识别已启用，清除确认展开。一致：绿色「已启用」结论句、红底确认块（文案、「先不清除」「确认清除」），确认块出现时收起「清除已保存」。差异：实现多「最近一次登录」「手机上重新登录」两行；其余是通用差异。
- **NarrowSettings**：430x820，手机访问已装未开启，验证码识别没装。一致：单列布局、分组跳转按钮三枚、通道卡折行、「开启手机访问」、验证码识别「下载并安装」。差异：Tailscale 说明句折行位置不同；验证码识别体积句同上。
