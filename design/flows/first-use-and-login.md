## 主流程（首次使用）

```
打开工具
  │
  ├─ 没同意过当前版条款 → 自动弹出条款弹窗（拒绝过的不再自动弹，只留横幅）
  │   ├─ 勾「我已阅读并同意《用户协议》与《隐私政策》」→ 点「我已阅读并同意」
  │   │   ├─ 保存成功 → 弹窗关闭，补一次登录检查和活动列表加载
  │   │   └─ 版本对不上 → 只提示，不写同意、不解锁
  │   └─ 「暂不使用」→ 横幅「还没有同意使用条款」，登录、活动列表、报名计划保持停用
  │
  ▼
启动检查（复用本机保存的登录）
  │
  ├─ 学校确认有效 → 胶囊「已登录」，旁边小字「HH:MM 校验」；自动加载活动列表
  ├─ 学校说失效（4001）→ 胶囊「登录已失效」+ 横幅「登录已失效。」带「重新登录」
  ├─ 从没登录过 → 胶囊「未登录」
  └─ 网络异常 → 胶囊「登录待确认」，先不用重新登录，点「刷新」再试
  │
  ▼
登录有效且活动列表加载后
  ├─ 没看过本版引导（TOUR_VERSION = 3）→ 自动开始五步引导，可随时跳过
  └─ 看过 → 直接进新工作台（时刻表 + 计划栏）
```

## 登录：点哪里、走哪条路

「登录 / 重新登录」按钮在**登录状态卡**里：悬停或点击顶栏的登录胶囊打开。失效时横幅上也有「重新登录」。
点了先打开**重新登录对话框**，按「有没有保存账号 × 有没有装验证码识别」分四种情况（设计 9.3，电脑和手机同一套）：

| 情况 | 对话框里做什么 |
|---|---|
| 保存了账号，也装了验证码识别 | 先确认，点「自动登录一次」，电脑自己填账号密码、认验证码（连续认错 3 次转人工） |
| 保存了账号，没装验证码识别 | 电脑填账号密码，用户只输图里的 4 位验证码，点「提交验证码」 |
| 没保存账号 | 填账号、密码；「登录成功后保存到这台电脑（加密存储）」默认不勾，只用这一次；装了识别就由电脑认验证码，没装就再输验证码 |
| 保存的密码学校不认 | 写明自动登录已暂停，要输新的账号密码；勾选保存会替换旧的 |

- 三种表单下面都写「登录时，工具会替你勾选学校登录页上的《隐私协议》。」
- 对话框底部保留「改用浏览器登录」：走旧的浏览器登录窗口，在浏览器里完成登录。
- 登录成功：对话框写「重新登录成功。」（计划运行中写「重新登录成功，报名计划照常继续。」），随后学校校验，胶囊换成新的校验时刻。
- 没成功：学校说账号或密码不对 → 写明并暂停用保存的密码；超时、取消各有一句；其余写「这次没登录上，可以再试一次，或者改用浏览器登录。」
- 关闭对话框时如果这一场还在等验证码，会一起取消，不在后台挂着登录进程。

## 逐步说明

| # | 用户动作 | 系统状态 | 可见反馈 | 失败后的下一步 |
|---|---|---|---|---|
| 条款 | 勾选并点「我已阅读并同意」 | 本机没有当前版同意记录 | 首次自动弹条款弹窗；拒绝后只留横幅「还没有同意使用条款」+「查看条款」 | 「暂不使用」→ 学校动作都停用，随时可从横幅或「设置 → 程序」回来同意 |
| 1 | 双击打开工具 | 读取本机登录信息，向学校校验 | 胶囊「检查登录…」，不提前写「已登录」 | 窗口空白 → 装 WebView2 运行时 |
| 2a | （无动作） | 学校确认有效 | 胶囊「已登录」+「HH:MM 校验」（**不显示剩余时间**），列表自动加载 | —— |
| 2b | （无动作） | 学校说失效（4001） | 胶囊「登录已失效」，横幅带「重新登录」 | 走「登录：点哪里、走哪条路」 |
| 2c | （无动作） | 从没登录过 | 胶囊「未登录」；时刻表空态「登录后查看活动」 | 打开登录状态卡点「登录」 |
| 3 | 在重新登录对话框里完成登录 | 按四种情况之一 | 「正在登录…」→「重新登录成功。」 | 见上表的失败说明；也可改用浏览器登录 |
| 4 | （自动） | 校验通过、列表加载 | 首次自动开始五步引导：这是活动时刻表 → 勾选想报的活动 → 核对计划，再点开始 → 开始以后看这里 → 出问题先看顶部 | 可跳过；随时从帮助「重看引导」 |
| 5 | 关闭工具再打开 | 复用同一数据根的登录信息 | 先校验；通过后胶囊「已登录」，**不弹登录** | 只有学校明确说失效才需要重新登录 |

## 运行中登录失效（决策 014 第 8 条）

| 时机 | 行为 |
|---|---|
| 等开放时（离最早一场开放 > 100 秒） | 计划不停；电脑能自动登录就自动登录（胶囊「自动登录中…」）；不能的，计划栏写「HH:MM:SS 前重新登录，计划照常继续」并给「重新登录」 |
| 有场次在提交，或离开放 ≤ 100 秒 | 只做电脑自动登录；用户点重新登录得到「现在来不及重新登录」的说明；做不了的场次以「登录失效」结束 |

## 文案边界

- 胶囊**不显示「约剩 N 小时」或「临近失效」**，只写上次校验时刻；有效多久学校不公布，工具不估算。
- 按钮只在「确实登录过」的状态叫「重新登录」，首次使用和状态未知叫「登录」。
- 登录从有效变失效时，填了飞书机器人地址才推一次提醒，消息不含账号。

## 已知边界（按现状写）

- **b-amendment-005**：「学校说密码错一次就停」只部分落地。界面和后端已按 `safe_error=bad_password` 实现暂停与提示，
  但登录进程现在把密码错也报成 `bad_response`，所以真实运行里还停不下来；断网等其他失败不计入暂停。
- **文案残留**：帮助三步说明第 1 步、未登录时胶囊说明、浏览器登录成功的结果框，仍按旧的「在打开的浏览器中完成登录」
  「登录剩余时间以学校校验为准」写，和新的重新登录对话框、不估算剩余时间的规则不一致，待 UI-B 返修。
- **b-amendment-009**：手机页第 10 节的整页视觉重排没做；手机上的重新登录规则（四种情况、账号密码默认不保存）已落地。
- 真实 4001 重新登录、断网恢复、EXE 重开复用登录的真机复核，留给用户在授权后完成。
