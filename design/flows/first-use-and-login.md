> 对应决策：[001 命名](../decisions/001-product-naming.md)、[006 登录态持久化](../decisions/006-session-persistence.md)、
> [009 可重播产品引导](../decisions/009-replayable-product-tour.md)、[014 新工作台](../decisions/014-workbench-ui.md)。
> UI-B 2026-11-04 实现：先同意条款 → 登录 → 登录有效且列表加载后自动五步引导；

## 主流程（首次使用）

```
打开工具
  │
  ├─ 条款横幅："还没有同意使用条款。"（已同意同版则跳过）
  │   └─ 用户点「查看条款」→ 条款弹窗 → 「我已阅读并同意」
  │       ├─ 保存中 → 按钮禁用"正在保存…"
  │       ├─ 保存成功 → 横幅消失，进入下一步
  │       ├─ 版本不匹配 → 提示重下完整版本，零写入
  │       └─ 「暂不使用」→ 横幅保持，登录/刷新/开始计划全部停用
  │
  ▼
启动检查（复用保存的登录态）
  │
  ├─ 有登录态，真实校验有效 → 胶囊「已登录 · 上次校验 HH:MM」
  │   └─ 自动加载活动列表
  │
  ├─ 有登录态，真实校验失效（4001）→ 胶囊「登录已失效」
  │   └─ 顶栏显示「重新登录」按钮
  │
  ├─ 没登录态或从没登录 → 胶囊「未登录」
  │   └─ 顶栏显示「登录」按钮
  │
  ▼
活动列表加载后
  │
  ├─ 新用户（TOUR_VERSION=3 首次）→ 自动开始五步引导
  │   （引导不阻塞操作，可随时跳过）
  │
  └─ 老用户 → 直接进入新工作台（时刻表 + 计划栏）
```

## 逐步说明

| # | 用户动作 | 系统状态 | 可见反馈 | 失败后的下一步 |
|---|---|---|---|---|
| 条款门 | （自动） | 本机无同意记录 | 顶部横幅「还没有同意使用条款」，按钮「查看条款」 | 「暂不使用」→ 登录/刷新/开始计划全部停用；「我已阅读并同意」→ 进登录 |
| 1 | 双击打开工具 | 窗口启动，读取本地登录态 | 顶栏时间胶囊（北京时间）+ 登录胶囊（状态未知时） | 窗口空白 → 装 WebView2 运行时 |
| 2a | （无动作） | 有登录态，真实校验有效 | 胶囊「已登录」+ 上次校验时刻（**不显示剩余时间**），列表自动加载 | —— |
| 2b | （无动作） | 有登录态，真实校验失效（4001） | 胶囊「登录已失效」，顶栏「重新登录」按钮 | 点「重新登录」走第 3 步 |
| 2c | （无动作） | 没登录态或从没登录 | 胶囊「未登录」，顶栏「登录」按钮 | 点「登录」走第 3 步 |
| 3 | 点「登录」/「重新登录」 | 弹出真实浏览器登录窗 | 在浏览器里输学号、密码、图形验证码 | 打不开登录页 → 查校园网/代理；关窗或超时 → "登录没完成"，可再试 |
| 4 | 浏览器点登录提交 | 脚本保存登录态，关浏览器 | 结果框「登录成功」+「正在加载活动列表」；自动拉活动列表 | 登录后学校校验没过 → "登录没完成"，再试一次 |
| 5 | （自动，首次） | 登录有效 + 列表加载 | 自动开始五步引导（登录状态 → 活动列表 → 筛选 → 选择 → 设置开始 → 查看结果） | 可跳过；随时可从帮助「重看引导」 |
| 6 | 关闭工具再打开 | 复用同一数据根的登录态 | 先校验；通过后胶囊「已登录」，**不弹登录窗** | 只有真实 4001 才需要重新登录 |

## 登录失败后的四种路径（UI-B 已落地）

| 情况 | 走哪条路 | 备注 |
|---|---|---|
| 学校明确返回密码错 | **暂只部分落地**：界面和后端已按 safe_error=bad_password 实现暂停（UI-B b-amendment-005），但登录进程（禁改）把密码错、bad_response、传输异常都报成 bad_response，真实运行里还停不下来 | 需另开小任务改 login_relay.py |
| 网络断/超时 | 结果框「登录没完成」+ 具体原因 | —— |
| 验证码连续错 3 次 | 转人工（停用自动验证码，用户手动输） | —— |
| 没装验证码识别组件 | 高级功能横幅 + 设置抽屉"验证码识别未安装" | —— |

## 运行中登录失效（决策 014 §8）

| 时机 | 行为 |
|---|---|
| 等开放时（离开放 > 100 秒） | 计划不停；能自动登录就自动登录；不能自动登录的写「HH:MM:SS 前重新登录，计划照常继续」 |
| 开放前 100 秒内 + 提交中 | 只做自动登录；不能自动登录的场次以「登录失效」结束 |
| 点「重新登录」（开放前 100 秒内） | 弹说明"现在来不及重新登录" |

## 文案边界

- **首次使用显示「登录」；真实失效（4001）显示「重新登录」**——两个词不混用，用户一眼知道是第一次还是续期。
- 胶囊**不再显示「约剩 N 小时」或「临近失效」**——顶栏只显示上次校验时刻（决策 014 改）。
- 登录失效推飞书只推一次、消息不含账号（架构方案）。
