## 一、精简原则与红线

1. **只删废话，不删事实与风险**：保留「名额已满非工具故障」「待核对需回活动页核实」「报后不可退」「100 秒内来不及重登」「非官方不声称合规」「自动登录会代勾《隐私协议》」「单账号使用」等全部核心判断与条款披露。
2. **去掉重复前提**：同一页面已有上下文时（例如在「设置」卡片内不再每句重复「保存在这台电脑」），删去冗余解释。
3. **统一短句节奏**：列表卡片、横幅、浮卡与手机端共用同一套紧凑短句，减少换行撑高。
4. **短不等于书面**：不用「勿、此、即刻、非、曾、期间、关乎」这类公文字；为了说成人话多几个字可以接受。防误会的否定句（如空列表的「这不是登录问题」）保留。

## 二、逐条对照表（覆盖 6 块界面）

### 1. 主窗口与列表（顶栏浮卡、筛选、空状态）

| 位置 | 现文案 | 新文案 | 理由 |
|---|---|---|---|
| 顶栏 · 北京时间浮卡说明（`ready`） | 报名按这个时间执行，运行中会定时自动校准。工具不会改电脑的时间。 | 报名按这个时间执行，工具不改电脑的时间。 | 去掉「运行中会定时自动校准」重述；「此」「系统时间」换成口语 |
| 顶栏 · 北京时间浮卡说明（`down`） | 还没校准成功，多半是连不上授时服务。校准之前不能开始报名，不影响查看活动。 | 暂时连不上授时服务；校准前可查看活动，不能开始计划。 | 删「还没校准成功，多半是」，先给原因与可执行范围 |
| 顶栏 · 登录浮卡副标题（`expired`） | 可以自动登录一次 / 只需要输验证码 / 要在浏览器里登录 | 可自动重登一次 / 需输入验证码 / 请在浏览器登录 | 统一四字到六字动作提示，减少浮卡头折行 |
| 列表空状态 · 学校无活动（`zero`） | 学校当前没有返回活动 / 这不是登录问题。稍后点“刷新”再看，学校发布新活动后会出现在这里。 | 学校当前没有活动 / 这不是登录问题，学校发布新活动后会出现在这里。 | 保留「这不是登录问题」：空列表最常见的误会就是以为登录坏了；删掉「稍后点刷新再看」 |
| 列表空状态 · 加载失败（`error`） | 连不上学校站点，已保存的登录不受影响。检查网络后点“刷新”。 | 连不上学校站点，已存登录仍在。检查网络后点“刷新”。 | 压缩「已保存的登录不受影响」为「已存登录仍在」 |
| 列表空状态 · 未登录（`idle`） | 在这里输入账号密码或用学校登录页，登录后活动会自动加载。 | 登录后自动加载活动。 | 登录方式在弹窗里选，空态只需交代后果 |
| 列表空状态 · 筛选无结果（`noresult`） | 一共 N 场。换个关键词，或清除筛选看完整列表。 | 共 N 场，请换个关键词或清除筛选。 | 去掉重复「看完整列表」 |

### 2. 设置抽屉（高级功能、自动登录、程序组）

| 位置 | 现文案 | 新文案 | 理由 |
|---|---|---|---|
| 高级功能 · 手机访问主说明（`missing`） | 从手机查看活动、开始和停止计划。手机只是遥控器，真正报名的还是这台电脑，所以电脑要开着、不能睡眠。 | 用手机查活动、开始或停止计划；报名还是这台电脑在做，电脑别睡眠。 | 保留「电脑在做 + 别睡眠」两个重点；「启停」「勿」换成口语 |
| 高级功能 · 手机访问未开启说明（`off`） | 选一条通道再开启。没开启时不监听端口，手机连不上电脑。 | 先选通道再开启；关闭时不监听端口。 | 删显而易见的「手机连不上电脑」 |
| 高级功能 · 验证码识别已启用（`on`） | 版本 1.2.0。电脑会自己认验证码，连续认错 3 次再转给手机手动输入。 | 版本 1.2.0。自动识别验证码，连续错 3 次转手动。 | 保留 3 次上限，压缩人称铺垫 |
| 高级功能 · 验证码识别未启用提示（`off`） | 这一项关系到自动登录，所以装好了也不会自己打开。 | 关系到自动登录，装好后要手动启用。 | 正说动作；「关乎」「需」换成口语 |
| 高级功能 · 打开组件文件夹回执 | 已用资源管理器打开组件所在的文件夹。 | 已打开组件文件夹。 | 不需要报系统程序名「资源管理器」 |
| 程序 · 飞书提醒说明 | 建一个只有你自己的群，加一个自定义机器人，把地址贴在这里。报名结果和登录失效都发到这个群。 | 建一个只有你的群，加个自定义机器人，把地址贴在下面。报名结果和登录失效都发到这个群。 | 「个人群」容易读成「个人/群」，直接说「只有你的群」，防泄露要点更清楚 |
| 程序 · 版本与更新初始态（`idle`） | 只有点“检查更新”时才联网，下载前还会再确认。 | 点“检查更新”时才联网；下载前先确认。 | 精简连接词 |
| 程序 · 条款与隐私摘要行 | 你在 MM-DD HH:MM 同意了 X 版。用户协议、隐私政策和开源许可的全文都可以在这里查看。 | 已在 MM-DD HH:MM 同意 X 版。 | 右侧已有「查看条款」按钮，不重复解释可查看全文 |

### 3. 报名计划栏（草稿、运行、结果、停靠条）

| 位置 | 现文案 | 新文案 | 理由 |
|---|---|---|---|
| 计划栏 · 未登录副标题（`idle`） | 活动会在登录完成后自动加载。 | 登录后自动加载。 | 动词紧凑，卡片首屏不换行 |
| 计划栏 · 手机发起提示（`planSource`） | 这个计划是从手机开始的，在电脑和手机上都能看进度、停止。 | 从手机启动的计划，电脑与手机都可查看进度或停止。 | 压缩语气词「这个…都能」 |
| 计划栏 · 运行链路直连标记 | 直接提交，不经过活动页 | 直接提交 | 括号备用路写「改用页面点击（原因），详情页已打开」，主路径只需 4 字 |
| 计划栏 · 运行结果 · 已停止 | 已提交的场次保留原状态，还没提交的场次已取消。 | 已发出的保留结果，其余已取消。 | 从 21 字压到 13 字，事实不变 |
| 计划栏 · 运行结果 · 名额已满 | 学校的名额在开放后被报满了，不是工具出错。 | 名额满了，不是工具出错。 | 保留「不是工具出错」这个判据，「非…故障」换成口语 |
| 计划栏 · 运行结果 · 电脑睡眠 | 运行计划时别让电脑睡眠：在 Windows 电源设置里把睡眠改成“从不”，并保持插电。 | 电脑睡眠过。计划运行时把电源设置里的睡眠改成“从不”，并保持插电。 | 直给改法，并说清在哪里改 |
| 计划栏 · 跨 24h 开始前提醒 | 有场次在 24 小时以后才开放，计划要一直运行到那时。这段时⁠间电⁠脑不能关机或睡眠。 | 有场次 24 小时后才开放，这段时间电脑别关机、别睡眠。 | 压短但不用「期间」「勿」 |

### 4. 顶部横幅与内联反馈

| 位置 | 现文案 | 新文案 | 理由 |
|---|---|---|---|
| 顶部横幅 · 重复启动（`second`） | 工具已经开着。 / 刚才又打开了一次，已切回这个窗口。同一台电脑只运行一份，免得同一场被提交两遍。 | 工具已在运行 / 已切回当前窗口，同一电脑只运行一份。 | 单条横幅尽量一行显示完整 |
| 顶部横幅 · 旧数据迁移成功（`migrated`） | 已把旧版本的数据搬到新位置。 / 登录、设置和运行记录都在，不用重新登录。位置在设置的“本机数据”里。 | 旧版数据已迁移 / 登录、设置和记录已移至“本机数据”，无需重登。 | 合并冗余说明，直接指路设置入口 |
| 顶部横幅 · 旧登录未迁移（`migratefail`） | 旧版本的登录信息没能搬过来。 / 设置和运行记录已经搬好；重新登录一次就行，旧文件还留在原来的位置。 | 旧登录态未能迁移 / 设置和记录已迁移；重登一次即可，旧文件未删。 | 从 46 字压到 32 字 |
| 顶部横幅 · 时钟待校准（`clock === down`） | 北京时间还没校准。 / 校准后才能开始报名计划，不影响查看活动。 | 北京时间待校准 / 校准前可查看活动，不能开始计划。 | 与顶栏浮卡统一措辞 |
| 顶部横幅 · 断网运行中（`net === off`） | 网络断开了。 / 到点时还没恢复，这次报名会失败。恢复以后看一眼计划结果。 | 网络已断开 / 到点前未恢复则本次失败，恢复后看结果。 | 横幅一屏可见，省去 9 字 |

| 位置 | 现文案 | 新文案 | 理由 |
|---|---|---|---|
| 配对页 · 底部提示 1 | 配对码在电脑的“设置 → 手机访问”里，5 分钟内有效，只能用一次。 | 配对码在电脑“设置 → 手机访问”里，5 分钟内有效，只能用一次。 | 「5 分钟一次」会被读成「每 5 分钟换一次」，有效期和一次性要分开说 |

| 更多面板 · 电脑窗口说明 | 窗口被隐藏到后台时，可以从这里叫回来。 | 窗口藏到后台时，可以从这里叫回。 | 「从此」容易读成「从此以后」 |
| 离线告警说明 | 确认电脑开着、程序没退出。如果只是手机断网，电脑上的计划不受影响。 | 确认电脑没睡眠、程序没退出；只是手机断网的话，电脑照常报名。 | 补全「没睡眠」前提；「仅…时」换成口语 |

## 三、建议同步修订《文案规范》（待定，本次未改）

以下三条建议供后续定稿 [copywriting.md](../specs/copywriting.md) 时拍板，**本轮未改《文案规范》原文**：

1. **增加短句篇幅预算**：建议给顶部横幅正文设「标题 ≤ 10 字、说明 ≤ 28 字」，给设置子行副标题设「≤ 24 字（尽量不折三行）」，避免新工作台圆角卡片被解释性文字撑高。
2. **明确横幅动作按钮分工**：一次性通知固定单钮「知道了」；可收起持续状态统一双钮「主修复动作 + 收起」（收起后顶栏留状态提示点）；不可收起门禁不给关闭钮。
3. **统一手机端与桌面端短句口径**：手机端「名额已满」「已停止」「运行中防休眠提示」及「活动卡片时间前缀（`MM-DD` 替代长 `M月D日`）」建议与桌面端合并为同一份词表，后续不再两边各自写两套语气相近但长度不同的句子。
