## 1. 两个入口的分工

顶栏两个独立按钮：帮助（问号 SVG + 文字）和设置（齿轮 SVG + 文字）。各自的访问名称：

| 入口 | 功能分组 | 内容 |
|---|---|---|
| **设置抽屉**（`#settings`） | 高级功能组 | 验证码识别组件下载、无人值守重登开关 |
| | 登录组 | 保存的账号管理、删除、清空登录数据 |
| | 程序组 | 关闭窗口选项（每次询问 / 隐藏到后台 / 最小化到任务栏 / 直接退出）、版本与更新、本机数据目录、条款与隐私（**撤回同意**、查看条款） |
| **帮助**（`#dlg-help`） | 帮助正文 | 三步使用说明（确认登录 / 选活动并开始 / 看结果）、快捷键清单、页脚「重看引导」「知道了」 |

**运行中行为**：计划运行中两个入口都能打开，但以下动作禁用并写明原因：
- 设置抽屉：删除保存的账号（"计划运行中不可删除"）、关闭窗口选项正常、版本更新正常、**撤回同意禁用**（"报名计划运行中不能撤回同意，先停止计划。"）
- 帮助：页脚「重看引导」「知道了」都正常（关窗后仍可用 Esc 关闭）

### 设置抽屉的导航与锚点

抽屉顶部三组导航按钮：高级功能、登录、程序。点导航滚动到对应分组，底部固定"关闭"。
分组锚点：`#settings-section-advanced` / `#settings-section-login` / `#settings-section-app`。
程序组内**版本与更新**标题行右侧固定推进按钮（七态自变，状态切换后按钮停 0.8 秒防误点）。

### 帮助不含条款入口

帮助面板没有"查看条款"入口（原型 Main.dc.html:744-746 里没有），条款只在
「设置 → 条款与隐私」。`views/terms.js` 里从帮助归还焦点的分支仅作兜底保留。

### 设置抽屉的条款入口（含撤回）

设置抽屉程序组内的"条款与隐私"行放两个按钮：
- "查看条款"（`#btn-settings-terms`）——只读查看
- "撤回同意"（`#btn-terms-withdraw`）——仅在同意过且**计划不在运行/就绪态**时可用；
  计划 running/ready 时按钮禁用，并在按钮下方显示原因
  「报名计划运行中不能撤回同意，先停止计划。」（原型 Main.dc.html:738）。撤回后条款横幅重新出现，
  登录、自动登录、刷新、开始计划全部停用，已保存账号不删。撤回不可恢复（需重新同意）。

## 2. 视觉与交互

### 设置抽屉

与新工作台顶栏并列打开的 drawer，从右侧滑入（约 400px 宽，窄档可能缩到 320px）：
- 头部：标题"设置" + 关闭按钮（`#btn-settings-close`）
- 三组导航按钮水平排列，当前选中下划线
- 正文：分组标题 + 控件行，滚动区域内三组都可见
- 条款与隐私行在程序组底部，带两个按钮（查看条款 / 撤回同意），撤回原因显示在按钮下方
- Esc 关闭抽屉，焦点回顶栏设置按钮

### 帮助

延续既有黑底点阵标题 + 白纸正文面板：
- 标题"使用帮助"，副标题"三步完成一次报名"，+ X 关闭
- 三步使用说明（确认登录 → 选活动并开始 → 看结果），没有适用范围说明
- 快捷键清单（F5 刷新登录状态和活动列表 / Ctrl + F 跳到搜索框 / Esc 关闭弹窗和详情卡 /
  Tab 在按钮和活动之间移动 / 空格 勾选或取消当前活动）
- 底部按钮行：重看引导、知道了
- 计划运行中"重看引导"禁用，说明"计划结束后可重看引导"
- Esc 关闭，焦点回顶栏帮助按钮

### 条款弹窗共享行为

帮助和设置的条款弹窗是同一个 `#dlg-terms`，由调用方决定是"只读查看"还是"同意/撤回"语义：
- 帮助 → 只读查看（同意按钮隐藏，关闭按钮显示）
- 设置查看 → 只读查看
- 设置撤回 → 显示撤回确认（"确认撤回同意？撤回后登录、自动登录、刷新、开始计划全部停用"）

## 3. 版本与更新（已迁入设置程序组）

旧帮助面板里的版本更新已迁入设置抽屉程序组，**帮助面板不再有版本/更新相关内容**。
七态推进按钮固定在"版本与更新"标题行右侧，状态自变后按钮停 0.8 秒防误点。

| 状态 | 可见 | 按钮 |
|---|---|---|
| 未检查 | "只有点“检查更新”时才联网，下载前还会再确认。" | 检查更新 |
| 检查中 | "正在检查…" | 禁用 |
| 有新版 | "发现新版本 X。" | 查看发布页 |
| 相同 | "已是最新正式版。" | 检查更新 |
| 预览版 | "当前是预览版本，最新正式版是 X，不建议换回旧版本。" | 查看发布页 |
| 无正式发布 | "还没有正式发布的版本。" | — |
| 失败 | "暂时无法检查更新。" | 重试 |

结果附本次检查时间，附说明"不会自动下载或安装，需要你去发布页手动下载"。

## 4. 本机数据目录（已迁入设置程序组）

旧帮助面板里的"打开数据目录"已迁入设置抽屉程序组，**帮助面板不再有数据目录按钮**。
显示说明"登录信息、设置和运行记录都只保存在这台电脑。卸载时默认不删，可在这里手动打开目录删除。"

## 5. 窄档适配

窗口 ≤720px 时：
- 设置抽屉缩到约 320px，三组导航按钮可能换行
- 帮助面板宽度降到 min(420px, 100vw - 32px)，底部按钮可能换行
- 关键按钮保持可点击，焦点环清晰

## 6. 行为证据

设置抽屉与帮助的契约由 `test_ui_contract.py` 的 `SettingsEntryContractTests` 和
`SettingsDialogBehaviorTests` 系列钉住：入口存在、两组内容不重复、条款入口两种语义、
撤回同意在计划运行中禁用、版本与更新在设置组且不在帮助里。
